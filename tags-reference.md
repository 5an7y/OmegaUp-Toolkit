# Tags de OmegaUp — Referencia

Los tags en OmegaUp son de una lista predefinida en la plataforma. Existen tres categorías con prefijos especiales, más tags de uso libre. Al menos una tag pública es requerida para subir un problema.

## Notas

- Los tags **no son case-sensitive** en las búsquedas de OmegaUp, pero deben escribirse exactamente como aparecen en esta lista.
- Puedes usar cualquier tag de texto libre, pero los que aparecen aquí son los reconocidos oficialmente por la plataforma.
- **Se requiere al menos una tag con `public: true`** para poder subir un problema.
- Para lecturas del curso, se recomienda combinar: `curso-omi-yucatan` + el `problemLevel*` correspondiente.
